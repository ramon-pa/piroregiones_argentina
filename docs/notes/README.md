# `docs/notes/` · Cuaderno de laboratorio

El registro de **construir** el pipeline, no su documentación: pruebas, caminos tomados y
abandonados, errores y su análisis, resultados con fecha ("medido el <fecha>").

Existe para que los docs de paso digan solo lo que es verdad hoy. Acá no hay límite de largo y nada
se borra.

## Convenciones

- Un archivo por tema: `NN-<tema>.md`, con el número del paso del que viene.
- Si el texto se movió desde otro doc, el archivo abre con un encabezado que fija el commit:

  ```markdown
  > **Movido de** `docs/03-burned_by_cover.md`, sección "Export" @ `abc1234` (2026-11-02).
  > Cuaderno de laboratorio: el registro de construir el paso, no su documentación.
  ```

- El texto se mueve tal cual. Reescribirlo es otra pasada.
